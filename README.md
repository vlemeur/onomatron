# onomatron

A character-level language model that generates names of characters from French
literature, from the classics to the modern era.

## Overview

Onomatron is a from-scratch journey through autoregressive language modeling,
following the spirit of Andrej Karpathy's [makemore](https://github.com/karpathy/makemore)
and his [Zero to Hero](https://github.com/karpathy/nn-zero-to-hero) series
